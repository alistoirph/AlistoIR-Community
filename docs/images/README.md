# Guide illustrations

These numbered figures are instructional illustrations, not captures of a live deployment. They use public example values and show expected results where explicitly labeled. Field/button names were checked against the AlistoIR 3.0 application source. Actual placement may vary with screen size.

The Markdown guides embed PNG files for convenient viewing. Editable SVG originals are in `source/`. No live browser tabs, credentials, private IP addresses, analyst data or alert evidence were used in these figures. Images supplement the copyable commands and field-by-field instructions; they do not replace them.
